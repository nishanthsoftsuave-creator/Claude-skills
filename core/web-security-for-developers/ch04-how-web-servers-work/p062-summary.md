# Chapter 4 Summary
(Source: PDF p. 62. The text above the "Summary" heading on this page is the end of WS-C04-004.)

## What the section covers
The chapter's closing recap of web server content types, plus a forward pointer to Chapter 5 (PDF p. 62).

## Recap of the chapter
- Servers return two kinds of content to HTTP requests: static resources such as images, and dynamic resources that run custom code (PDF p. 62). Defined in WS-C04-002.
- Static resources can be served straight from a filesystem or a content delivery network to make a site more responsive. Sites made wholly of static content are usually authored in a content management system, which lets non-technical administrators edit them in the browser (PDF p. 62). Covered in WS-C04-003.
- Dynamic resources are often written as templates: HTML mixed with programmatic instructions the server interprets. They typically read from a database or cache that shapes the rendered page (PDF p. 62).
- The most common database type is SQL, which stores tabular data under strict structural rules. Larger sites often use NoSQL, a newer kind that relaxes some of those constraints to scale better (PDF p. 62).
- Dynamic resources are written in a web programming language, and many are available (PDF p. 62). The dynamic-side details are in WS-C04-004.
