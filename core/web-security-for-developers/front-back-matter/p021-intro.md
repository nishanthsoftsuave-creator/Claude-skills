# Introduction - Opening Framing
(Source: PDF p. 21)

## What the section covers
The opening paragraphs of the Introduction, which set up the problem the whole book answers: why securing a website feels so hard for an individual developer.

## Meaning
- The internet looks deliberate, as if experts designed it and everything works for a good reason. The book says this impression is wrong: the network grew quickly and haphazardly, and what people now do on it goes far past what its original inventors pictured (PDF p. 21).
- Because of that unplanned growth, defending a website can look like a daunting task (PDF p. 21).

## Why it matters
- A website is an unusual kind of software. The moment it is released it is reachable by millions of users, and that audience includes an active, motivated community of hackers (PDF p. 21).
- Large companies regularly suffer security failures, and new data breaches are reported every week (PDF p. 21).
- This sets up the question the author poses: how can a single web developer on their own protect themselves against that? The rest of the Introduction and the book respond to it (PDF p. 21).
