# Chapter 2 Summary
(Source: PDF p. 42. Starts at the "Summary" heading on that page; the text above it is WS-C02-005.)

## What the section covers
The author's recap of Chapter 2, described as the "plumbing" of the internet, and a lead-in to the next chapter.

## The recap
- TCP provides reliable communication between internet-connected computers, each having an IP address (recaps WS-C02-002) (PDF p. 42).
- The Domain Name System supplies human-readable aliases for IP addresses (WS-C02-002) (PDF p. 42).
- HTTP is built on TCP. User agents such as browsers send HTTP requests to web servers, which reply with HTTP responses. Each request targets a specific URL, and the chapter introduced various HTTP methods (WS-C02-003) (PDF p. 42).
- Servers answer with status codes and send back cookies to start stateful connections (WS-C02-003 and WS-C02-004) (PDF p. 42).
- Encryption, in the form of HTTPS, can secure communication between user agent and server (WS-C02-005) (PDF p. 42).

## Lead-in to Chapter 3
The next chapter looks at what happens when a browser receives an HTTP response: how a page is rendered and how user actions can trigger more HTTP requests (PDF p. 42). See WS-C03-001.
