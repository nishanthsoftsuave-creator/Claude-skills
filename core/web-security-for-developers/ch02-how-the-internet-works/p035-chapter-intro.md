# Chapter 2 Introduction - How the Internet Works
(Source: PDF p. 35. The heading "The Internet Protocol Suite" starts lower on the same page and is covered in WS-C02-002.)

## What the section covers
The opening framing of Chapter 2: why a web security expert needs a firm grasp of the underlying web technologies and protocols, and what the chapter will cover (PDF p. 35).

## Meaning
- Becoming expert in web security requires understanding the web's underlying technologies and protocols (PDF p. 35).
- The chapter examines the Internet Protocol Suite, the set of rules governing how computers exchange data over the web (PDF p. 35).
- It also introduces stateful connections and encryption, which the author calls key elements of the modern web (PDF p. 35).

## Why it matters
Along the way the author promises to point out where security holes tend to appear in these technologies (PDF p. 35). INTERPRETATION: read the protocol material with that security eye.
