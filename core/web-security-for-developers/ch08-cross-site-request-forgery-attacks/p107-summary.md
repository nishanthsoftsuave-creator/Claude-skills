# Chapter 8 Summary - Cross-Site Request Forgery Attacks
(Source: PDF pp. 107-108. The text on PDF p. 107 above the "Summary" heading is WS-C08-006.)

## What the section covers
The chapter's recap of the threefold CSRF defence plus reauthentication, and a pointer to the next chapter (PDF pp. 107-108).

## Recap
- Attackers can use web requests from other sites to trick your users into undesired actions. The defence against this cross-site request forgery is threefold (PDF p. 107).
- First, make GET requests free of side effects, so clicking a malicious link does not change server state (WS-C08-003) (PDF p. 108).
- Second, use anti-CSRF cookies to protect the other request types (WS-C08-004) (PDF p. 108).
- Third, set those cookies with a SameSite attribute so requests generated by other sites arrive without them (WS-C08-005) (PDF p. 108).
- For very sensitive actions, require the user to reauthenticate (WS-C08-006). This adds another layer against CSRF and protects users who accidentally leave themselves logged in on shared or stolen devices (PDF p. 108).
