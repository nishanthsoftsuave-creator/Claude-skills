# Chapter 3 Summary
(Source: PDF pp. 48-49. Starts at the "Summary" heading near the bottom of PDF p. 48; the text above it is WS-C03-004. PDF p. 50 has no extracted text.)

## What the section covers
The author's recap of Chapter 3 and a lead-in to the chapter on web servers.

## The recap
- The chapter reviewed how browsers convert the HTML that describes a page into the interactive visual representation on screen (PDF p. 48).
- The rendering pipeline parses HTML into a Document Object Model, applies styling from CSS files, and then lays out the DOM nodes on screen (recaps WS-C03-002) (PDF p. 48).
- It also covered the browser security model: the browser runs JavaScript from script tags under strict security rules (recaps WS-C03-003) (PDF p. 49).
- A simple HTTP conversation showed the many other browser duties beyond rendering: rebuilding HTTP from TCP packets, verifying security certificates and securing communication with HTTPS, and storing and sending cookies (recaps WS-C03-004) (PDF p. 49).

## Lead-in to Chapter 4
The next chapter looks at the other end of the HTTP conversation: the web server (PDF p. 49).
