# Chapter 3 Introduction - How Browsers Work
(Source: PDF p. 43. The heading "Web Page Rendering" starts lower on the same page and is covered in WS-C03-002.)

## What the section covers
The framing paragraph that opens Chapter 3 on why developers need to understand browsers and what the chapter will cover (PDF p. 43).

## Meaning
- Most internet users reach websites through a browser. To build secure sites you must understand how the browser turns HTML, the markup used to describe pages, into the interactive visual page on screen (PDF p. 43).
- The chapter covers how a modern browser renders a page and highlights the protections it applies for the user, collectively called the browser security model (PDF p. 43).
- It also previews the ways hackers try to get around those protections (PDF p. 43).
