# User Feedback (section lead-in)
(Source: PDF p. 894, from the "User Feedback" heading onward. The first lines of the page, about choosing an orchestrator, belong to C10-009.)

## What the section covers
The introduction to the user feedback section: why feedback matters even more for AI applications than for ordinary software, what it can be used for, and the privacy caution that goes with it.

## Why it matters
- In software generally, user feedback has always served two purposes: judging how well the application performs and guiding its development (PDF p. 894).
- In AI applications its role is larger. User feedback is proprietary data, and data is a competitive advantage. A well-designed feedback system is needed to create the data flywheel that Chapter 8 discussed (PDF p. 894).
- Feedback can personalize a model for individual users and can also train later versions of the models (PDF p. 894).
- As data becomes scarcer, proprietary data grows more valuable. A product that launches quickly and draws users early can collect data to keep improving its models, which makes it hard for rivals to catch up (PDF p. 894).

## Assumptions and caveats
User feedback is user data, so the same cautions apply as with any data: respect user privacy, and users have a right to know how their data is used (PDF p. 894).
