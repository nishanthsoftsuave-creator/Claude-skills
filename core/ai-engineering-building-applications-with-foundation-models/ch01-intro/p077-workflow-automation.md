# Workflow Automation

## End of data organization: structured extraction
- Simple extraction use cases include pulling information from credit cards, driver's licenses, receipts and tickets, and contact details from email footers. More complex ones include extracting data from contracts, reports and charts (PDF p. 77).
- The author cites an estimate that the IDP (intelligent data processing) industry will reach $12.81 billion by 2030, growing 32.9% per year (PDF p. 77).

## Meaning of workflow automation
The stance is that AI should ultimately automate as much as possible (PDF p. 77).
- For end users: boring daily tasks such as booking restaurants, requesting refunds, planning trips and filling out forms (PDF p. 77).
- For enterprises: repetitive tasks such as lead management, invoicing, reimbursements, handling customer requests and data entry (PDF p. 77).
- A particularly exciting use: using AI models to synthesize data that can improve the models themselves. AI can create labels for data, with humans looped in to improve them. Data synthesis is discussed in Chapter 8 (PDF p. 77).

## Tools and agents
- Many tasks require access to external tools. Booking a restaurant might need permission to use a search engine to find the number, to call from the user's phone, and to add an appointment to the calendar (PDF p. 77).
- AIs that can plan and use tools are called agents. Interest in agents "borders on obsession", but the author says it is not entirely unwarranted: agents could make every person far more productive and generate far more economic value (PDF pp. 77-78).
- Agents are a central topic of Chapter 6 (PDF p. 78).

## Transition
