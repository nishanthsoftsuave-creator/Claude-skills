# Preface - What This Book Is Not
(Source: PDF pp. 15-16, tail PDF p. 17. The text at the top of PDF p. 15 is the end of the preceding section, covered in P-002. The heading starts on PDF p. 16.)

## What the section covers
What the book deliberately does not do, and the background knowledge that makes a reader more effective.

## Meaning
- It is not a tutorial. It mentions specific tools and includes pseudocode snippets to illustrate concepts, but does not teach how to use a tool. It offers a framework for choosing tools, with discussion of trade-offs between solutions and the questions to ask when evaluating one. Tutorials for a given tool are usually easy to find online, and AI chatbots are decent at helping people start with popular tools (PDF p. 16).
- It is not an ML theory book. It does not explain what a neural network is or how to build and train a model from scratch. Theoretical ideas are explained when directly relevant, but the book is practical, aimed at building successful applications for real problems (PDF p. 16).

## Prerequisites
- One can build foundation-model applications without ML expertise, and the book can be read with no ML background. Still, basic ML and statistics knowledge helps build better applications and spares "unnecessary suffering" (PDF p. 16).
- Concepts that make the reader more effective (PDF pp. 16-17):
  - Probability: sampling, determinism, distribution.
  - ML: supervision, self-supervision, log-likelihood, gradient descent, backpropagation, loss function, hyperparameter tuning (PDF p. 17).
  - Neural network architectures: feedforward, recurrent, transformer (PDF p. 17).
  - Metrics: accuracy, F1, precision, recall, cosine similarity, cross entropy (PDF p. 17).
- A reader lacking these should not worry: the book gives brief high-level explanations or points to resources for catching up (PDF p. 17).
