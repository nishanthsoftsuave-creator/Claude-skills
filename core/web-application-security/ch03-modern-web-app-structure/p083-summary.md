# Chapter 3 Summary
(Source: PDF p. 83 from the "Summary" heading; PDF p. 84 is blank)

## What the section covers
The closing statement of Chapter 3: what the new technologies mean for attackers and defenders, and how much software engineering knowledge a security specialist needs.

## Key points
- Modern web applications are built on a number of new technologies that older applications did not have. That expanded functionality increases the surface area, so many more forms of attack can target today's applications than the websites of the past (PDF p. 83).
- To be a security expert in today's application ecosystem you need not only security expertise but also some level of software development skill (PDF p. 83).
- The top hackers and security experts of the decade bring deep engineering knowledge together with security skills. They understand the relationship and architecture between the client and the server of an application, and can analyse an application's behaviour from the perspective of a server, a client, or the network in between (PDF p. 83).
- The best understand the technologies behind those three layers of a modern web application. As a result they understand the weaknesses inherent in different databases, client-side technologies and network protocols (PDF p. 83).
- You do not have to be an expert software engineer to become a skilled hacker or security engineer, but these skills help and are very valuable. They speed up research and allow you to see deep, difficult vulnerabilities that you would not otherwise find (PDF p. 83).
