# Preface - Minimum Required Skills
(Source: PDF p. 19)

## What the section covers
The explicit checklist behind the phrase "intermediary-level background in software engineering", plus a note on the book's code language and on how difficulty ramps up.

## The minimum criteria (PDF p. 19)
The reader should be able to do each of the following:
- Write basic CRUD (create, read, update, delete) programs in at least one programming language.
- Write code that runs on a server, meaning backend code.
- Write at least some code that runs in a browser, meaning frontend code, usually JavaScript.
- Know what HTTP is, and make or at least read GET and POST calls over HTTP in some language or framework.
- Write, or at least read and understand, applications that use both server-side and client-side code and talk to each other over HTTP.
- Be familiar with at least one popular database, for example MySQL or MongoDB.

Experience beyond this list is a bonus and makes the book easier to use. The author calls these skills the minimum for following the examples.

## Language note
Most code examples are written in JavaScript for simplicity, so that client and server code share one language. The author says most examples carry over to other languages with little effort (PDF p. 19).

## How the book is paced
- Topics are ordered to rise in difficulty at a manageable pace (PDF p. 19).
- The author tried to be as verbose as possible in explanations. Whenever a new technology is introduced, a short background and overview of how it works comes first (PDF p. 19).
